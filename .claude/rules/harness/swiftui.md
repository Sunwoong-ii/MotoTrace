# SwiftUI

## 상태

- 상태 관찰 방식(`ObservableObject` / `@Observable`)은 기존 코드를 따르고, 섞어 쓰지 않는다.
- `@State`는 뷰가 소유하는 값에만 쓰고 `private`으로 둔다. 외부에서 받는 값은 `let`, `@Binding`, 관찰 객체로 받는다.

## 뷰 작성

- `body`에는 무거운 연산이나 부수효과를 두지 않는다.
- 뷰 생명주기에 묶인 비동기 작업은 `.task`로 실행한다. 뷰가 사라지면 자동으로 취소된다.
- `ForEach`에는 안정적인 식별자를 쓴다. 배열 인덱스를 id로 쓰지 않는다.
- `AnyView`로 타입을 지우는 대신 `@ViewBuilder`나 `Group`을 쓴다.
- 새 뷰에는 프로젝트 관례에 따라 `#Preview`를 추가한다.

## 접근성·디자인

- 인터랙티브 요소에는 접근성 식별자(테스트용)와 필요한 접근성 라벨을 둔다.
- 프로젝트에 디자인 시스템(에셋 카탈로그 색, 토큰, 공용 컴포넌트)이 있으면 그것을 쓰고, 색·폰트·간격 값을 하드코딩하지 않는다.
